# Atomic English

Ứng dụng theo dõi tiến bộ học tiếng Anh theo tinh thần Atomic Habits kết hợp mức năng lượng hàng ngày (6 buổi/tuần, 60 phút/ngày, tự động chia đều thời lượng các kỹ năng và bảo toàn 1 ngày nghỉ linh hoạt/tuần).

## Cách triển khai trên GitHub Pages
1. Tạo repository mới trên GitHub (ví dụ `atomic-english`).
2. Tải toàn bộ 4 file (`index.html`, `manifest.json`, `icon.svg`, `README.md`) lên nhánh `main`.
3. Vào **Settings → Pages → Build and deployment → Source: Deploy from a branch**, chọn nhánh `main` và thư mục `/ (root)`, rồi bấm **Save**.
4. Mở đường dẫn `https://<ten-github-cua-ban>.github.io/atomic-english/` trên điện thoại và chọn **Thêm vào màn hình chính (Add to Home Screen)** để dùng như app thật.
